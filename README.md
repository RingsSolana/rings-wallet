# Rings Wallet

A Solana wallet for Chrome (Manifest V3) with the Rings private balance built in: a public and a private balance,
private sends, moves between the two, swaps through the Rings relay, and a Wallet Standard provider for websites.

## Download

[Download Rings Wallet (rings-wallet.zip)](https://github.com/RingsSolana/rings-wallet/releases/latest/download/rings-wallet.zip)

To install it, unzip it, open `chrome://extensions`, turn on Developer mode, click Load unpacked and choose the
unzipped folder.

## Fee

0.1% of the wallet's own sends, swaps and moves between the public and private balances, paid in the same coin to
Rings and shown on every review screen. Transactions that websites ask the wallet to sign carry no fee.
