# Rings Wallet

Rings Wallet is a Solana wallet with a private balance built in, made by Rings ([rings.run](https://rings.run)). Send,
receive and swap privately, and use any Solana app. It is available as a Chrome extension and as an Android app in the
Solana dApp Store.
